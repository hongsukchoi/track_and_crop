# Track and Crop

Track an object in a video and create a cropped video that follows it. Uses [SAM2](https://github.com/facebookresearch/sam2) for object tracking.

## Setup

```bash
# Run the setup script (creates conda env, installs dependencies, downloads model)
./setup.sh

# Activate the environment
conda activate track_and_crop
```

## Quick Start

```bash
# 1. Annotate videos with interactive GUI
python bbox_annotator.py video1.mp4 video2.mp4

# 2. Open http://localhost:8080, draw bboxes, click "Finish"

# 3. Run generated script
./run_track_and_crop.sh
```

## Bbox Annotator

Interactive web GUI for annotating bounding boxes on multiple videos.

### Usage

```bash
python bbox_annotator.py video1.mp4 video2.mp4 video3.mp4
```

Or use glob patterns:

```bash
python bbox_annotator.py videos/*.mp4
```

### Workflow

1. Open `http://localhost:8080` in your browser
2. **Select video** from the dropdown menu
3. **Click top-left** corner of the object to track
4. **Click bottom-right** corner of the object
5. Click **Save Bbox** to store the annotation
6. Select next video and repeat steps 3-5
7. Click **Finish & Generate Script** when done

### GUI Elements

| Element | Description |
|---------|-------------|
| Video dropdown | Switch between videos |
| Status | Shows current instruction |
| Coordinates | Displays current/saved bbox |
| Save Bbox | Saves bbox for current video |
| Clear | Resets current video's annotation |
| Finish | Generates bash script and exits |
| Smoothing slider | Adjust camera smoothing (0-0.95) |
| Crop Scale slider | Adjust crop region size (1.0-3.0) |

### Options

| Option | Description | Default |
|--------|-------------|---------|
| `--port` | Viser server port | 8080 |
| `--output-script` | Output bash script path | run_track_and_crop.sh |
| `--output-dir` | Directory for cropped videos | output |
| `--smoothing` | Default smoothing value | 0.8 |
| `--crop-scale` | Default crop scale | 1.5 |

### Example

```bash
python bbox_annotator.py \
    videos/*.mp4 \
    --output-script process_all.sh \
    --output-dir cropped_videos \
    --smoothing 0.85
```

### Output

The generated bash script contains one command per annotated video:

```bash
#!/bin/bash
# Generated by bbox_annotator.py

# video1.mp4
python track_and_crop.py \
    --video "/path/to/video1.mp4" \
    --bbox "100,150,400,500" \
    --output "output/video1_cropped.mp4" \
    --smoothing 0.8 \
    --crop-scale 1.5

# video2.mp4
python track_and_crop.py \
    --video "/path/to/video2.mp4" \
    --bbox "200,100,600,400" \
    --output "output/video2_cropped.mp4" \
    --smoothing 0.8 \
    --crop-scale 1.5
```

## Track and Crop

Core script that tracks an object and creates a cropped video.

### Usage

```bash
python track_and_crop.py --video input.mp4 --bbox 'x1,y1,x2,y2' --output output.mp4
```

### Options

| Option | Description | Default |
|--------|-------------|---------|
| `--video`, `-v` | Input video path | (required) |
| `--bbox`, `-b` | Initial bounding box `x1,y1,x2,y2` | (required) |
| `--output`, `-o` | Output video path | (required) |
| `--smoothing` | Camera smoothing (0=none, 0.9=very smooth) | 0.0 |
| `--crop-scale` | Scale factor for crop region | 1.5 |
| `--aspect-ratio` | Force aspect ratio (e.g., `16:9`) | bbox ratio |
| `--output-size` | Output resolution (e.g., `1280x720`) | auto |
| `--model-size` | SAM2 model: `tiny`, `small`, `base_plus`, `large` | large |
| `--fps` | Output video FPS | same as input |
| `--device` | `cuda` or `cpu` | auto-detect |

### Example

```bash
python track_and_crop.py \
    --video demo.mp4 \
    --bbox '950,277,1070,500' \
    --output output.mp4 \
    --smoothing 0.8 \
    --crop-scale 2.0
```

### Smoothing

The `--smoothing` option applies EMA (Exponential Moving Average) to reduce camera shake:

| Value | Effect |
|-------|--------|
| 0.0 | No smoothing (camera follows object exactly) |
| 0.5 | Moderate smoothing |
| 0.8 | Smooth camera motion (recommended) |
| 0.9 | Very smooth, cinematic feel |

## Get Pixel Location

Simple helper tool to find pixel coordinates on a single video.

### Usage

```bash
python get_pixel_location.py video.mp4
```

Open `http://localhost:8080` and click anywhere on the frame. Coordinates are printed to the terminal.

## Requirements

- Python 3.10+
- CUDA-capable GPU (recommended)
- ffmpeg (for audio preservation, installed automatically by setup.sh)
- ~2GB disk space for SAM2 large model checkpoint
